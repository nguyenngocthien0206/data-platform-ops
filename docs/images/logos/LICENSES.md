# Logos

Each logo is the vendor's own artwork, fetched on 2026-10-15 from the vendor's brand kit or, where the kit could not be downloaded directly, from the vendor's own site. The files are unmodified; the two PNGs were only scaled down to 256 px. They are used to name the product a part of the architecture runs on, nothing more: no endorsement by any vendor is implied, and every name and logo is a trademark of its owner. Follow each vendor's guidelines before reusing a file elsewhere.

`scripts/make_architecture.py` embeds these files in `docs/images/architecture.svg`; `tests/test_docs_images.py` checks that every logo it uses is listed here.
